## How to Get Listed

Your contributions are valued! You'll be added to this list when you:

- Submit a merged pull request
- Report a significant bug with detailed information
- Suggest a feature that gets implemented
- Improve documentation
- Help other users in discussions
- Responsibly disclose security vulnerabilities

## Recognition Levels

### Core Contributor
- Multiple significant contributions
- Active in code reviews
- Helps maintain the project

### Major Contributor
- Significant feature implementation
- Major bug fixes
- Substantial documentation improvements

### Contributor
- Bug fixes
- Feature enhancements
- Documentation updates
- Test improvements

### Community Helper
- Active in discussions
- Helps other users
- Reports bugs
- Suggests features
